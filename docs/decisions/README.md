# Decisões arquiteturais e científicas (ADRs)

- [ADR-0001 — fundamentação científica é documentação](ADR-0001-Science-Is-Documentation.md)

Novas decisões duráveis devem registrar problema, alternativas, consequências, estado, referências e impacto nos contratos, testes e portabilidade. As escolhas no GDD não substituem ADRs quando houver trade-offs.
