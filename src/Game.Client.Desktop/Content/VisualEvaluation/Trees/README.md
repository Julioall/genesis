# Árvore em billboard — protótipo de avaliação

Estas cinco imagens são cópias dos sprites adultos (`crescimento_08`) do pacote de árvores fornecido pelo usuário em `Spectators-of-Life/data/assets/tree/PNG_192px`. Elas servem somente para comparar uma apresentação híbrida de árvore em plano texturizado com a malha botânica procedural. Não são entradas da simulação, não determinam espécie, biomassa ou crescimento e ainda não foram escolhidas para o renderer final.

Arquivos usados: carvalho, pinheiro, bétula, outonal (mapeado ao perfil de bordo) e salgueiro. O pacote original declara sprites RGBA de 192 × 192 com alfa binário e pivô inferior central.
